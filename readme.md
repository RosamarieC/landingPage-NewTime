# Responsive Agency Landing Page

A modern, responsive landing page built using HTML and CSS.  
The project focuses on clean UI structure, responsive design, and user-focused layout principles.

## Live Demo
https://rosamariec.github.io/landingPage-NewTime/

## Features
- Fully responsive design
- Hero section with overlay background
- Service cards with icon components
- Value proposition grid section
- Clean semantic HTML structure
- Modern CSS techniques (Flexbox, Grid, clamp())

## Tools Used
- HTML5
- CSS3
- Responsive design techniques

## What I Practiced
- Converting UI ideas into structured layouts
- Creating reusable component styling
- Implementing responsive typography
- Improving visual hierarchy and spacing
